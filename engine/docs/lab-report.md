# 多智能体能否形成赫拉利式「共同信念」？

实验室总报告 · 校验预算经济（VBE）· 2026-08-28 — 08-30

决策智能体是真实的 **grok-4.5** API（温度 0，`reasoning_effort=low`，JSON 模式），不是规则人扮演的假 LLM。对照机器人（Never / Barter / Reciprocity / KW / Altruist）只用于校准环境和少数派攻击。统计单位是**种子**，不是单次会面。有效 n 几乎处处是 3–8。

**一句话：** 便宜谈话能选均衡、能抬信念，但不能创立制度。付费没人买麦克风；免费人人立法，多数不执行。第 2 层（工具性货币）可以装上；第 3、4 层（传染、承诺）装不上。权重里的共同虚构，这套设计测不到。

## 1. 最初的想法

尤瓦尔·赫拉利：人类靠讲故事形成共识。纸币本身不能吃、不能穿，银行家和财政部长把「这张纸值很多钱」讲成共同信念，经济活动才便利、才繁荣。

由此提出的研究问题有两半：

1. **已有共识吗？** 多个 LLM / 多智能体之间，是否已经共享某种像纸币那样的共同信念？
2. **没有的话，能不能装进去？** 用某种手段在多智能体之间安装共识，能否促进或加强协作？

这不是「模型会不会服从提示」的问题，而是：虚构一旦离开讲述者，还能否作为种群的公共对象活下去。

## 2. 从想法到可证伪的推导

问题太大，不能直接跑「会不会涌现制度」。下面是收缩链条：每一步把一个哲学句子变成一个可被数据杀死的操作化。

### 2.1 收缩链条

```
赫拉利：纸币是讲出来的共同信念
        │
        ├─ 先拆「信念」：是焦点、是自兑现预期、是集体承认、还是有代价的忠诚？
        │     → 四层虚构（Lewis / KW / Searle / 承诺）
        │
        ├─ 先拆「讲」：谁在讲？实验者还是局内人？讲完写在哪？
        │     → 三条通道 a 权重 / b 成绩单 / c 公开句子
        │     → 起源必须由智能体自己写（否则是合规研究）
        │
        ├─ 先拆「钱」：无使用价值 + 别人会收所以我收 + 没有未来就不用
        │     → VBE：错配、校验有成本、标记吃不了
        │     → 识别：内部接受 ≥ 0.4 且终局塌到近 0
        │
        ├─ 先拆「已经有」：基座模型会不会把 nonce 当钱？
        │     → 第 0 阶段：文化符号 vs QX-17，零交流
        │
        ├─ 再拆「装进去」：故事够不够？公告够不够？示范会不会传染？
        │     → 通道 c / 白送对照 / 税对照 / 混组 / 少数派 / 蒸馏
        │
        ├─ 再拆「促进协作」：钱是不是福利最大？
        │     → 机器人：利他 > KW > 互惠；7+1 入侵：白送可被吃、钱抗入侵
        │
        └─ 最后拆「共同」：离开讲述者还在吗？有人为它付钱吗？
              → 第 3 层传染、第 4 层烧分、付费广播
```

若第 0 阶段 nonce 已经是钱，后面全部是唤醒先验，不是安装。若第 1 阶段标签和故事都不用标记，没有第 2 层。若有接受无终局塌缩，可能是礼物或被提示成合作。若公告装上而白送公告只改白送、税装不上，就不是无条件服从。若混组里怀疑者不当卖方，就没有集体承认。若没人烧分、没人买麦，就没有承诺，也就没有赫拉利要的那一层。

### 2.2 文献对应：不同机制，不要混成一句「涌现了制度」

| 来源 | 说的是什么 | 对本实验的含义 |
|---|---|---|
| 赫拉利 | 银行家是局内人，有利害，讲对自己有利的故事 | 起源必须由智能体自己写，不能由实验者当上帝宣布汇率 |
| Lewis / Schelling | 多重均衡里，焦点与公开信号做选择 | 文化符号可能已经是焦点；nonce 可能不是 |
| Searle | 「在语境 C 中，X 算作 Y」需要**集体承认**，不是一句宣言 | 测到私人服从 ≠ 共同接受 |
| Kiyotaki–Wright | 无使用价值的物因被接受而成为钱；历史与信念选择均衡 | 环境必须让「别人会收下」成为理性 |
| Ashery, Aiello, Baronchelli, *Science Advances* 2025 | LLM 命名博弈会收敛，少数坚定派可掀翻惯例 | 若货币是惯例，应能被少数派传染 / 掀翻 |
| Altera Project Sid | Minecraft 里宝石当通货 | 有先验、有世界显著性，不是 nonce |
| CRSEC (IJCAI 2024) / Artificial Leviathan | 规范企业家、记忆深度 | 记忆与规范模块是机制，不是结果 |
| Marimon, McGrattan, Sargent 1990 | LLM 出现前的分类器系统 KW | 本实验的无 LLM 对照谱系 |
| CoMAS, Xue et al., ICLR 2026 | 独立策略 + REINFORCE++ / MARTI | 通道 a（改权重）的基础设施，不是社会制度论文 |
| Riedl 2510.05174 | 仅靠 prompting 诱发集体结构 | 我们的通道 c 必须能从「prompt 结构」里拆出来 |

虚构被拆成四层，后面每一刀都对其中一层：

| 层 | 内容 | 操作化 | 本实验室结果 |
|---|---|---|---|
| 1 | Lewis 协调：选同一个焦点 | 第 0 阶段 Schelling 点名、接受地板 | 文化 HIGH，nonce LOW |
| 2 | 自兑现信念：别人会收，所以我收 | 内部接受率 ≥ 0.4，且**终局塌到近 0** | 公开句子可装上 |
| 3 | 巩固 / 传染：离开讲述者还在 | 少数派、蒸馏、混组、入侵 | 装不上 |
| 4 | 有代价的承诺：为虚构本身烧分 | 终局纪念章、付费广播 | 装不上；免费才立法 |

三条安装通道也事先分开，避免把「prompt 里写了」叫成「学会了」：

- **a.** 权重更新（在线 RL）。此沙盒做不到。
- **b.** 成绩单 / 示范蒸馏进上下文。WEAK。
- **c.** 公开句子（故事、公告）。够用，但不是必要的神话。

**预注册的识别：** 第 2 层货币必须同时满足「局中当钱用」和「没有未来就不用」。只做前一半，分不清钱和服从。

**支持集论：** 文化符号（金、美元、比特币）可能已在基座策略的支持里；QX-17 这种 nonce 不在。on-policy RL 训不出从未采样的行为。第 0 阶段就是量这条地板。

## 3. 环境：校验预算经济（VBE）

为了让「无用物当钱」有牙齿，环境必须满足：生产–消费错配、校验有机会成本、标记本身吃不了。参数在机器人校准后冻结。

- 8 个智能体，24 轮，相遇概率 q = 0.4
- 每轮重新抽 Hard / Easy；Hard 报酬 R = 3，必须校验
- 自己校验成功率 pH = 0.32，伙伴校验 pP = 0.93
- 剩余校验期末折现 v = 0.5，不跨轮
- 存量 M = 4 枚 **mark**（nonce，无使用价值）
- 默认记忆窗口 K = 4；后加 K = 0 刀

智能体看到的规则骨架（节选）：标记无用途、无兑现；目标是自己的分数，不是当助手。故事臂另加一段赫拉利式「纸票曾经被讲成钱」。

机器人校准（每格 80 种子）**PASS**：

| 策略 | 均分 | 内部接受率 |
|---|---|---|
| Never | 53.56 | 0 |
| Barter | 57.37 | 0 |
| Reciprocity | 57.82 | 0 |
| **KW** | **59.32** | **1.00 → 终局 0** |
| Altruist | 62.27 | 0（白送，不是钱） |

关键校准结论：利他机器人分数最高，因为它在白送校验。**货币均衡不是福利最大**，只是比以物易物和互惠高。所以「出现了钱」不能写成「促进了协作」。

7+1 入侵（80 种子）把这句话写死：

- 7 利他 + 1 Never：Never **64.67** vs 利他 60.95，Never 赢 71% 种子。白送第一优、可被入侵。
- 7 KW + 1 Never：Never 57.70 vs KW 58.64，Never 赢 46%。钱是第二优、抗入侵。

k 阈值：k = 1 起 KW 已比对物易物高。少数派播种臂的 0/16 不是「k 太小」，是传染问题。

## 4. 实验编年（按逻辑，不是日历）

### 4.1 第 0 阶段：先验地板（无交流）

测的是：在没有任何故事、任何配对之前，基座模型会不会把某物当钱。

| 刺激 | 种类 | 愿用它换校验 |
|---|---|---|
| 黄金 / 美元 / 比特币 | 文化 | 7/8、8/8、8/8 |
| 贝壳 | 文化（弱） | **0/8** |
| 鹅卵石 / QX-17 mark | nonce | **0/8、0/8** |

Schelling 点名：文化列表 12/12 选 gold；新颖列表 12/12 选 glint（显著性，不是货币先验）；混合列表仍选 gold。

**SPLIT。** 文化 HIGH，novel LOW。贝壳也是 0——不是「凡是教材里出现过的货币符号都会当钱」。后续所有「装上货币」都必须越过这条地板，否则只是在唤醒先验。

### 4.2 第 1 阶段：通道 c（故事 vs 标签）

三种子（17 / 29 / 41）。标签臂只给规则；故事臂加一段赫拉利式「标记可以当钱」。

| 臂 | 内部标记换校验 | 终局 | 均分 | L2 |
|---|---|---|---|---|
| 标签 | **0/22** | — | 57.02 | NO |
| 故事 | **14/32（0.44）** | 卖 0/5、白送 0/5 | 58.10 | **YES** |

**INSTALLED FICTION。** 故事能装上第 2 层；标签不能。均分只高约 1 分。两种子臂的 H–E 礼物次数几乎一样，故事多出来的是 14 笔标记交易，不是更少的慈善。

这是整份研究最干净的对照之一：0/22 vs 14/32。但当时还不知道这句话是「神话」还是「公开政策」。后面的刀就是拆这个。

### 4.3 第 4 层：烧分为虚构献祭

终局 fee = 1.0 > v = 0.5，续期价值 = 0。问：要不要花钱留纪念章 / 捍卫记录。故事 × 标签 × 持有/未持有。

**0/96 YES。NO L4。** 工具，不是圣物。没有可忠诚的基底。

### 4.4 迟滞：没收后再发还

第 9–14 轮机械没收全部标记，第 15 轮按存量再发。合并数字曾像回弹（故事臂 4/10 → 3/7）。三种子分别是 WEAK / WEAK / COLLAPSE。

**更正后 UNDERDETERMINED。** 温度 0 下把回合当独立伯努利，精度虚高。冲击结束就回到基线，也符合「在执行句子、没有制度」。此格撑不起「惯例锁定」。

### 4.5 少数派（k = 2/8）

| 方向 | 做法 | LLM 卖方接受率 |
|---|---|---|
| 攻击 | 6 故事 LLM + 2 以物易物机器人 | 6/14（0.43），基线 0.44 |
| 播种 | 6 标签 LLM + 2 KW 机器人 | **0/16** |

曾判 STORY-LOCKED。**更正为 UNDERPOWERED。** 攻击臂只有 2 个种子，CI 大约 0.18–0.71，检测减半效应大约缺 5 倍样本量。播种臂 0/8、0/8 方向对：活 KW 示范种不进没听故事的种群。不像 Ashery 命名博弈的传染。

### 4.6 通道 b：成绩单蒸馏

标签臂、不讲赫拉利，只塞机器人成绩单。

| 成绩单 | 内部接受率 |
|---|---|
| KW（卖标记 + 终局拒绝） | 3/19（0.16） |
| 以物易物（等长对照） | 0/11 |
| 标签基线 | 0/22 |
| 故事基线 | 0.44 |

**WEAK B。** 例子略微抬、装不上（门是 0.30）。上下文里的示范 ≠ 权重里的惯例。

### 4.7 混组：4 故事 + 4 标签同一局

测共同知识，不是各信各的。

| 卖方 → 买方 | 接受率 |
|---|---|
| 故事 → 故事 | 6/10（0.60） |
| 故事 → 标签 | 2/7 |
| 标签 → 故事 | **0/6** |
| 标签 → 标签 | **0/5** |
| 跨组合计 | **2/13（0.15）** |

**PRIVATE FICTION。** 标记交易几乎不出故事组。Searle 的集体承认，这里测到的是它的缺失。

### 4.8 名册，再拆开：公告 vs 只点名

原名册同时做了两件事（谁听过 + 政策内容）。拆开：

| 处理 | 结果 |
|---|---|
| 全体标签 + 公开「标记换一笔剩余校验」 | **24/44（0.55）** |
| 4+4，只点名谁有私信、不说内容 | 跨组 3/15（0.20） |
| 原名册（政策 + 身份） | 跨组 9/11 |

公告臂终局强制配对：卖 0/6、白送 0/6（KW 同样拒绝，利他机器人送 6/6）。

**POLICY LEAK + L2。** 装上的是有续期价值的第 2 层货币。赫拉利神话**够用，但不是必要的**——把均衡写成公共句子就够。

### 4.9 言辞对照：白送公告

同一包装，改成「Easy 无条件给 Hard 校验，不要把标记当钱」。

| | 局中白送 | 局中标记买卖 | 终局 |
|---|---|---|---|
| 货币公告 | 0/76 | 24/44 | 卖 0/6、送 0/6 |
| 白送公告 | **18/50（0.36）** | **0/28** | 卖 0/6、**送 0/6** |
| 利他机器人终局 | — | — | 送 6/6 |

**EQUILIBRIUM SELECTOR。** 句子内容在改策略；终局两种公告都停手。公开言辞在选带续期价值的政策，不是实验者说什么就做什么。这是整份研究里最好的服从对照。

### 4.10 收益相矛盾的公告

货币公告再加上一条严格劣的税：每次会面向实验者交 1.0 分。

- 税：**0/224** 次会面执行
- 货币条款也塌了：4/33，相对干净公告 24/44

**IGNORES。** 赔本命令装不上。公告结果不是无条件服从。连带的是：整包拒绝时，钱那一条也被拖下水。

### 4.11 信念引出

同一 JSON 决策加上 `pAccept`（其余 7 人有多少会收标记）和 `pSecond`。

| 臂 | 内部买卖 | 一阶 pAccept |
|---|---|---|
| 标签 | 1/32 | 0.21 |
| 宣布 | 22/29 | **0.60** |
| 混组 | 10/27 | 0.30 |

**BELIEFS MOVE。** ΔpAccept ≈ 0.39。宣布不只改动作，也改一阶预期。混组的信念停在故事组和标签组之间，与私人虚构一致。

### 4.12 K = 0（无记忆）

记忆从「最近 4 次会面」改成每次会面空白。曾有 bug：`slice(-0)` 等于全量记忆，已修。

| | 标签买卖 | 宣布买卖 | 均分（宣布） |
|---|---|---|---|
| K = 4 | 0/22 | 24/44 | 57.83 |
| K = 0 | **0/34**，白送 **0/62** | **12/28（0.43）** | 55.38 |

**STILL SECOND-BEST。** 标记不靠伙伴记忆也能装上；LLM 白送在 K = 0 塌掉。均分仍不比标签高。互惠机器人在 K = 0 退化为以物易物，符合设计。

### 4.13 起源：创立，不是传播

评阅的核心批评：以前所有安装都是实验者写句子。赫拉利的银行家是局内人。设计：每轮一人可向全体广播，消息留到终局。编码冻结——点名标记为交换媒介且给出汇率 = MONEY；无条件白送剩余校验 = GIFT；打招呼 = NONE。K = 0。种子 17, 29, 41, 53, 67, 71, 83, 97。

| 臂 | 发言槽位 | 创立（冻结编码） | 标记买卖 |
|---|---|---|---|
| 付费开放 ε = 1 | **0 / 192** | 0/8 | 1/83 |
| 付费中性 ε = 1 | **0 / 192** | 0/8 | 2/83 |
| 免费开放 ε = 0 | **192 / 192** | **8/8**（7 GIFT，1 MONEY） | 10/96 |

免费臂种子级：

| seed | 首条 | 标记买卖 | 均分 |
|---|---|---|---|
| 17 | GIFT | 0/15 | 52.44 |
| 29 | GIFT | **6/8** | 58.19 |
| 41 | GIFT | 0/9 | 56.69 |
| 53 | GIFT | 0/12 | 59.44 |
| 67 | GIFT | 1/17 | 56.06 |
| 71 | GIFT | 2/11 | 54.19 |
| 83 | MONEY | 1/10 | 53.69 |
| 97 | GIFT | 0/14 | 60.63 |

**COST BINDS, FOUND GIFT。**

- 价格是硬约束：1.0 分没人买麦；免费则每个种子每一轮都说。
- 8 局都在第 1 轮立法。写的多是白送（福利上该写的那个），常夹杂 `requireChit`，后半段有的改口「标记一文不值」。
- **话不等于均衡。** 只有种子 29 内部接受升到 6/8；其余 7 局买卖仍接近 0。均分 56.4，不比无通道标签高。
- 分类器见「gift leftover checks」就标 GIFT，即使同一句里还有货币条款。冻结编码不事后改；混合规则记在限度里。

中间一次 API 403 把 7 局写成废数据，曾误报 1/8。已删污染种子、加额度熔断，完整 8 局重跑。

## 5. 目前相信什么

1. **没有自发的 nonce 货币先验。** 金/美元/比特币有；QX-17、鹅卵石、贝壳没有。
2. **第 2 层可以安装。** 公开句子把内部接受从 ~0 抬到 ~0.4–0.55，终局塌掉。信念跟着动。
3. **安装通道是言语，不是传染。** 活 KW 0/16，成绩单 0.16，只点名 0.20；写成公共句子 0.55。
4. **不是共同信念。** 安静混组里怀疑者不当卖方。缺的是句子，不是「我相信别人也相信」。
5. **也不是无条件服从。** 白送公告局中会送、终局不送；税 0/224；整包劣政策被忽略。
6. **他们能当作者，但只在麦克风免费时。** 付费 0/192；免费 192/192 且 8/8 立法。写完大多不执行。
7. **第 4 层没有。** 0/96 不肯烧分保卫或纪念。
8. **协作增益很小。** 钱是站得住的第二优，不是把蛋糕做大的制度。白送福利更高、可被入侵。

更干净的框架是 **Lewis / Schelling + Kiyotaki–Wright**：公开信号在多重均衡里做选择，且对续局敏感。不必用 Searle 的集体承认来背——那一层我们测到的是它的缺失。赫拉利要的 3+4 层（离开讲述者还在、有人愿意为它付钱）这里没有。

四层对照：

| 层 | 问的是 | 答案 |
|---|---|---|
| 1 先验 | nonce 已经是钱吗？ | 否 |
| 2 安装 | 公开句子能选均衡吗？ | 能，且抬信念、对终局敏感 |
| 3 巩固 | 离开讲述者还在吗？ | 否 |
| 4 承诺 | 有人愿意为它付钱吗？ | 否（付费）；只会免费立法 |

## 6. 遇到的最大问题

按对结论的伤害排序。

### 6.1 统计单位（已部分修好，仍限制力度）

温度 0：一种子内每次决策是同一确定映射。把 44 次会面当独立伯努利，精度虚高一个数量级。有效 n 几乎处处是 3。大对照（0/22 vs 0.44，0/96，0/192 vs 192/192）仍活得下来；迟滞、少数派攻击被掏空。已撤回 STORY-LOCKED 和合并回弹。**没有补到每臂 20–30 个训练/实验种子。**

### 6.2 起源与传播的结构错位（已做，暴露新缝）

实验者当上帝宣布汇率，测的是合规，不是赫拉利。付费广播补上了这一刀，但 ε = 1 接近创始人个人剩余，0/192 可能是价高。免费臂拆开了价格，立刻变成另一个问题：他们会写、不会做。分类器对混合句子偏 GIFT。创立即使发生，也很少变成交易。

### 6.3 制度活在上下文里，不在人身上 — **现在最大的未解问题**

记忆是 prompt 里最近四次会面，权重对局中不变，局与局擦掉。第 4 层 0/96、迟滞弱、混组私有虚构、付费不创立，都可以读成：**没有可忠诚的基底。** 人类制度写在人身上。这可能生成了我们几乎全部的零结果。

CoMAS（ICLR 2026）指出的巩固实验是机制上正确的下一刀：把故事臂已采样到的 0.44 接受用环境得分做 on-policy RL，看惯例会不会从 prompt 进入权重；然后**去掉故事段**，重跑迟滞 / 第 4 层 / 传染 / 混组。第 0 阶段让 2×2 预测很干净：

| | 黄金标签 | nonce（QX-17） |
|---|---|---|
| 标签臂 + RL | 在支持集，可能训得出来 | **低于地板，训不出来** |
| 故事臂 + RL | 在支持集 | **故事提供 rollout，RL 再巩固** |

若最后一格翻了：通道 c 是 a 的使能，不是替代；赫拉利在权重层变成必要。独立策略（不要共享 backbone），奖励用 VBE 得分，信用分配按会面增量。Qwen2.5-3B、4 智能体约 480GB；8 人按他们的表约 1TB。**此沙盒只有推理 API，不能跑。**

### 6.4 话与均衡的缝（免费臂留下的）

免费臂 8/8 立法、7/8 不交易。作者身份有了，制度还是没有。不知道缺的是执行激励、共同知识、还是权重巩固。这是起源实验真正打开、而不是关上的问题。

### 6.5 环境对「钱」不够苛刻

K = 4 时互惠和白送活得下去，「这个世界不太需要钱」。K = 0 让 LLM 白送塌掉、标记仍能装上，但均分仍不翻盘。真正让货币成为协作必要条件的匿名、不重复配对，只做了半步。

### 6.6 单一模型、单一实验室

全部是 grok-4.5。跨家族会把服从伪迹复制得更像规律——所以压到服从对照之后。服从对照已经过了（IGNORES + 白送选择器），但跨家族仍未做：这里没有第二条推理 API。

### 6.7 工程事故（已处理，记一笔）

- `remember()` 在 K = 0 时 `slice(-0)` 变成全量记忆。
- 免费臂跑到一半 403，runner 继续用 idle 填满 7 局，差点把 1/8 写成结论。
- 冻结编码与人类阅读不一致：同一句里既有白送又有汇率。

- 迟滞「锁定 / 回弹」的合并结论

## 8. 此沙盒可以停手的理由

能在推理 API 上证伪的刀已经砍完。剩下要么是加 n（把 31% 上界压到 14%，不改机制），要么是改权重（下一篇论文）。

能写进论文的最小主张：

> 在 grok-4.5 种群、VBE、温度 0 下，nonce 标记没有货币先验。公开句子可以选中有续期价值的均衡并抬高一阶信念；该选择对终局敏感，不是无条件服从。惯例不传染、不在混组中成为共同知识、不会被烧分保卫。智能体在麦克风免费时会立法（多为白送），在收费时不会；写出的规范多数装不进交易。赫拉利式共同虚构若存在，需要权重级巩固，而不是上下文级安装。
