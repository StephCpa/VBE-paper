# VBE Paper Materials

This repository contains the manuscript and reproducibility materials for:

**Public Rules, Executed Behavior, and Welfare in a Language-Model Economy**

The package is organized as follows:

- `paper/` — AAMAS LaTeX source, bibliography, official class/style files, and the compiled PDF of the current revision (`VBE-paper1-aamas2027-r3.pdf`).
- `figures/` — submission figures. `VBE-x1-fig-mechanism.pdf` and `VBE-x1-fig-scope.pdf` (Figures 1–2 of the current revision) and the supplementary figures (`VBE-x1-supp-seed-level.pdf`, `VBE-x2-supp-accounting.pdf`, `VBE-x2-supp-curves.pdf`, `VBE-x2-supp-endgame.pdf`) are generated by `figures/scripts/make_x1_figures.py` from frozen artifacts. Earlier schematic figures and their editable PowerPoint are kept for history and are no longer used by the manuscript.
- `engine/` — the TypeScript VBE environment, analyzers, tests, frozen study traces, and the X0, X1, and X2 zero-call reanalysis artifacts.
- `reports/` — study protocols, reports, audit records, the second- and third-round review responses, follow-up protocols, Supplement S1, venue/submission notes, and the AI-assistance disclosure.
- `reports/VBE-paper1-r2-change-log.md` and `reports/VBE-paper1-r3-change-log.md` —
  file-level and claim-level records of the revisions of 2026-10-01 and 2026-10-08.

## Rebuilding the manuscript

From `paper/`, compile with the official AAMAS class and bibliography:

```bash
pdflatex -interaction=nonstopmode VBE-paper1-aamas2027.tex
bibtex VBE-paper1-aamas2027
pdflatex -interaction=nonstopmode VBE-paper1-aamas2027.tex
pdflatex -interaction=nonstopmode VBE-paper1-aamas2027.tex
```

The source reads figures from `paper/figures/`. The AAMAS class needs the Libertine, newtx, and Inconsolata font packages (on Debian/Ubuntu: `texlive-fonts-extra`, `texlive-latex-extra`, `texlive-plain-generic`); without them microtype's font expansion fails on bitmap fallbacks.

To regenerate the revision figures from the frozen data (requires matplotlib, and the X1 and X2 artifacts below):

```bash
python3 figures/scripts/make_x1_figures.py
```

## Re-running the engine checks

The engine uses Node.js with TypeScript stripping. No API credential is stored in this repository. The deterministic environment tests can be run with:

```bash
cd engine
node --test src/lib/vbe/env-payoff-accounting.test.ts src/lib/vbe/env.test.ts
```

The zero-call frozen-trace reanalysis is generated by:

```bash
cd engine
node --experimental-strip-types src/lib/vbe/reanalyze-welfare-review-x0-v1_1.ts
node --experimental-strip-types src/lib/vbe/reanalyze-welfare-review-x0-v1_1.test.ts
```

The X0 artifacts are retrospective exploratory analyses of frozen traces. They do not add model calls and do not alter the frozen W-CO, W-RG, or W-SGB protocols.

The X1 audit for the second review round replays every frozen W-CO, W-RG, and W-SGB run through the frozen engine, reconstructs the prompt behind each of the 14,010 decisions, and produces the exact welfare accounting, fixed-state comparisons, money funnel, and supplementary inference used in the revision:

```bash
cd engine
node --experimental-strip-types src/lib/vbe/reanalyze-welfare-review-x1.ts
node --test src/lib/vbe/welfare-review-x1.test.ts src/lib/vbe/env-exhaustive.test.ts
```

The X2 boundary audit for the third review round (endgame by exact round, exact-round history comparisons, giving after unreciprocated transfers, encounter-index denominators, and seed-clustered intervals) builds on the X1 replay:

```bash
cd engine
node --experimental-strip-types src/lib/vbe/reanalyze-welfare-review-x2.ts
node --test src/lib/vbe/welfare-review-x2.test.ts
```

The Paper 1 test set — `env*.test.ts`, `welfare-*.test.ts` except `welfare-crowding-out.test.ts`, `reanalyze-welfare-review-x0-v1_1.test.ts`, `paper1-scope-exploratory.test.ts`, and the X1 and X2 tests — passes on a clean clone. Tests for the earlier E-BUY and founder studies, two W-CO bridge tests, and the all-analyzer keyless test fail with `ENOENT` because their frozen inputs are not part of this package. Six frozen-manifest artifacts are missing here and should be added before the supplement is finalized: `online-source-quarantine.json`, `buyer-capability.json`, `provider-health-plan.example.json`, and the three `provider-health-welfare-*-plan.json` files. All 89 hashes of frozen artifacts that are present verify.

## Data and privacy

The repository contains public research artifacts, aggregate/frozen traces, code, and manuscript materials only. API keys, local machine paths, private credentials, transient build directories, and provider request secrets were excluded. See `reports/VBE-paper1-ai-assistance-disclosure.md` for the planned disclosure and `reports/VBE-paper1-supplement-router.md` for the artifact map.
