**Version:** 1.5 · 2026-10-01  
**Purpose:** preserve the full audit trail while keeping `VBE-paper1-submission-draft.md` focused on the W-CO→W-RG→W-SGB causal chain. This router does not change any study's evidential status.

## Main-paper retention rule

Keep a result in the main paper only if it does one of four jobs:

1. discovers the H–H path;
2. causally identifies the H–H execution channel;
3. locates the behavioral scope-expansion boundary;
4. establishes a necessary system-layer distinction used in the discussion.

Everything else remains auditable here and in the existing reports, but it must not compete with the main claim.
